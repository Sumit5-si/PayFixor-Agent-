================================================================================
  PAYFIXOR AGENT DASHBOARD — ERROR DIAGNOSIS REPORT
  Date: 2026-09-05
  Problem: Dashboard shows all zeros/empty despite Google Sheet receiving data
================================================================================

SUMMARY (HINDI):
Tumhara GharSansar website se jab payment cancel hoti hai to data Google Spreadsheet
me ja rha hai (ye sahi kaam kr rha hai), BUT PayFixor Agent Dashboard me kuchh nhi
dikh rha hai. Iska reason ye hai ki Google Spreadsheet aur PayFixor Agent Dashboard
ke beech me KOI CONNECTION HI NAHI HAI. Dono alag-alag kaam kr rhe hain.

================================================================================
                         ROOT CAUSE ANALYSIS
================================================================================

Tumhare system me 3 cheezein hain:
  1. GharSansar Website (E-commerce) → Razorpay Payment Gateway
  2. Google Spreadsheet (Google Apps Script / Razorpay webhook → Sheet)
  3. PayFixor Agent Dashboard (Backend + Frontend)

PROBLEM: #2 aur #3 ke beech KOI BRIDGE/CONNECTION NAHI HAI.

Jab tum payment cancel karte ho:
  - Razorpay "payment.failed" webhook bhejta hai
  - Tumhara Google Apps Script us webhook ko catch karke Google Sheet me data daal deta hai ✅
  - BUT PayFixor backend ko ye webhook kabhi MILTA HI NAHI ❌

───────────────────────────────────────────────────────────────────────────────

PROBLEM:
PayFixor ka webhook endpoint (/api/webhooks/razorpay) exist karta hai, but REAL
Razorpay webhook kabhi aata hi nahi kyunki:

1. .env me RAZORPAY_KEY_ID = "rzp_test_your_key_id" (PLACEHOLDER value!)
2. .env me RAZORPAY_KEY_SECRET = "your_razorpay_key_secret" (PLACEHOLDER value!)
3. .env me RAZORPAY_WEBHOOK_SECRET = "your_webhook_secret_here" (PLACEHOLDER value!)

client.py line 21-25:
  self.is_mock = (
      not self.key_id or
      self.key_id.startswith("rzp_test_mock") or
      self.key_secret == "mock_secret"
  )
  
Yahan "rzp_test_your_key_id" ko check karo:
  - startswith("rzp_test_mock") → False (kyunki "rzp_test_your_key_id" hai, "rzp_test_mock" nhi)
  - So is_mock = False, matlab REAL Razorpay client create hoga
  - BUT real key_id aur key_secret FAKE placeholder hain
  - To koi bhi Razorpay API call FAIL hogi

ALAG SE, signature verification (line 116-118):
  if not signature or not webhook_sec:
      return self.is_mock
      
  - is_mock = False (kyunki placeholder key "rzp_test_" se start nhi hota as mock)
  - To agar signature khali aaye ya webhook_secret placeholder ho, to return False
  - Matlab real Razorpay webhook aaye bhi to SIGNATURE VERIFICATION FAIL HOGI

RESOLUTION:
- .env me APNA REAL Razorpay Test Key ID dalo (jo tumne Razorpay Dashboard se liya)
  Example: RAZORPAY_KEY_ID="rzp_test_ABC123XYZ"
- .env me APNA REAL Razorpay Test Key Secret dalo
  Example: RAZORPAY_KEY_SECRET="abc123secretxyz"
- .env me APNA Webhook Secret dalo (Razorpay Dashboard → Webhooks → Secret)
  Example: RAZORPAY_WEBHOOK_SECRET="whsec_abc123"

ERROR #3: hmac.new() — SILENT FAILURE IN SIGNATURE VERIFICATION
Severity: ★★★★☆ HIGH
File: backend/app/razorpay/client.py (Line 123-131)
───────────────────────────────────────────────────────────────────────────────

PROBLEM:
Line 123-131 me signature verification try/except block me hai:
  try:
      expected_signature = hmac.new(...)
      return hmac.compare_digest(expected_signature, signature)
  except Exception:
      return False

Agar koi bhi error aaye (wrong secret, encoding issue, etc.) to ye SILENTLY
return False kar deta hai. Tumhe koi error message ya log NAHI milega.
Matlab webhook aaye bhi to signature fail ho aur tumhe pata bhi na chale.

RESOLUTION:
- Backend logs check karo (terminal/console me) jab webhook aaye tab
- Debugging ke liye except block me print/logging add karo:
    except Exception as e:
        print(f"HMAC Verification Error: {e}")
        return False

ERROR #5: WEBHOOK SE PAYMENT DATA DATABASE ME SAVE NAHI HO RAHA
Severity: ★★★★☆ HIGH
File: backend/app/razorpay/webhooks.py (Lines 112-124)
───────────────────────────────────────────────────────────────────────────────

PROBLEM:
_handle_payment_failed() method me (line 112-124):
  1. Ye existing Payment record dhundta hai database me: select(Payment).where(Payment.payment_id == payment_id)
  2. Agar payment pehle se database me NAHI hai to kuchh bhi nhi karta — bas {"status": "failure_recorded"} return karta hai
  3. Koi NEW Payment record CREATE NAHI karta

Matlab agar Razorpay se "payment.failed" webhook aaye aur us payment_id ka record
pehle se database me na ho (jo hoga NAHI kyunki tum pehli baar payment kr rhe ho),
to webhook data simply IGNORE ho jayega.

Same problem _handle_payment_success() (line 100-110) me bhi hai.

KYA HONA CHAHIYE:
Webhook handler ko chahiye ki agar payment exist nahi karti to EK NAYA Payment record
create kare database me. Currently wo sirf existing records UPDATE karta hai.

RESOLUTION:
_handle_payment_failed() aur _handle_payment_success() methods me logic add karna
padega jo:
1. Pehle check kare ki payment exist karti hai ya nhi
2. Agar nahi hai to NAYA Payment record create kare (Razorpay webhook payload se
   data extract karke — amount, method, status, error_code etc.)
3. Sath me corresponding Customer record bhi create karna padega agar nahi hai
4. Agar payment exist karti hai to update kare (ye currently ho rha hai)
